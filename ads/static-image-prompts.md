# Glowling — 5 native static image prompts (Nano Banana 2 / Pro)

Built on the Nano Banana Pro prompting protocol (lighting first, camera and lens specified, avatar in frame, negative space for text overlay) and the Master Doc rule that **the images that perform best show the pain exaggerated at the worst possible state.** Three of the five below are pain-state images. Two are desire/payoff images, so the matrix has emotional range when we mismatch them against the 5 copies.

## Model + run settings for all five

- **Model:** `nano_banana_2` (photorealistic lifestyle; no rendered text inside the image, headlines go on top as Meta text overlay on launch)
- **Aspect ratios:** generate each at **1:1** (Feed), **4:5** (Feed portrait), and **9:16** (Stories / Reels). Three exports per prompt.
- **Resolution:** 4k
- **Reference image to attach:** `Boy_drawing_on_glowing_board_161c9065.jpg` (our hero shot from Shopify Files). Attach to **S2, S3, S4, S5** at MEDIUM influence — the board must look right but is a prop in a scene. Do **not** attach it to S1 (board is intentionally absent from that scene).
- **Negative space:** all five prompts reserve a specific region of the frame for a headline overlay, so the same image works across the 1:1 Feed, 4:5 vertical, and 9:16 Stories crops.

## How to run them

1. **Generate** each prompt at 1:1 (Feed), 4:5 (Feed portrait) and 9:16 (Stories / Reels). Three exports per static, 15 image files total.
2. **Attach the reference image** `Boy_drawing_on_glowing_board_161c9065.jpg` for S2, S3, S4, S5. Do not attach it for S1.
3. **Check for the usual Nano Banana failure modes** before sign-off: studio equipment visible in frame (regenerate), brand logos visible (regenerate), model-perfect faces instead of real ones (regenerate), empty negative space missing or filled (regenerate).
4. **Upload each 1:1 export** to Shopify Content Files once approved. Send the five CDN URLs back and I'll pull them into the Meta ad account via `/adimages` and wire up the 25 creatives in the paused campaign.

## Why these five give the matrix its emotional range

- Three pain states (S1, S2, S5) to hit the "worst possible outcome exaggerated" rule from the Master Doc.
- Two desire / payoff states (S3, S4) so the mismatch grid still has rest for the eye between pain ads.
- Two feature the **parent avatar** in the frame (S1, S2), one features the **WFH parent avatar** (S3), one focuses on the **child** as the symbol of the outcome (S4), one features the **grandparent avatar** (S5). Each of the five angles in `ads/longform-ads.md` has a native-fit visual AND four mismatch visuals that still make narrative sense.
- The grandparent image (S5) does not just sell the gift angle; it carries a universal "money spent on failed gifts" idea that reads for parents too, which is why the matrix allows C5 (gift) copy against S1 (ledger) static without confusion.
