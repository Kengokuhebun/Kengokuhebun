# Native image prompts: one per long-form swipe

Paste each prompt into your image generator. Each image goes with the matching copy in `ninu-swipe-copy-paste-ready.md`.

**Settings for every one:** 4:5 for the feed, 2k, generate 4 versions and pick the least glossy and most ordinary-looking one. No product, logo or text is in any of them. That is on purpose, so the image stops the scroll and the copy does the selling.

---
