## Ad set setup in Ads Manager (about 10 minutes)

Meta has blocked the Ads Launcher app, so this is done by hand. Everything below matches the R17 ad set.

1. **Ads Manager → R1_Ninu → Ad sets → + Create.** Name: `BF Statics - US W25-44 - 2026-11-08`.
2. **Conversion:** Website, pixel "Shopify: shthwvvd 1785014874 business's pixel", event **Purchase**.
3. **Budget:** Daily **£55**. Bid strategy: Highest volume.
4. **Audience:** United States, age **25 to 44**, gender **Women**. Turn **Advantage+ audience off** ("Use your audience controls").
5. **Placements:** Manual. Facebook **Feed, Stories, Reels**. Instagram **Feed, Stories, Reels**. Untick everything else.
6. **Each of the 4 ads:**
   - Identity: Facebook Page **Ninu**.
   - Format: single image. Upload its image and paste its primary text, headline and description from above.
   - Website URL, **Shop Now** button and URL parameters from the top of this file.
   - **Advantage+ creative:** open "Advantage+ creative enhancements" and **untick every option**, including text improvements, visual touch-ups, music and adding overlays. Turn **off "Multi-advertiser ads"**.
7. **Publish with the ad set switched OFF.** R1_Ninu is active, so a new ad set that's on starts spending £55 a day straight away. Turn it on when you're ready.
8. **Check before turning on:** the product page shows $49.99 with no struck-through $62.49 and no "price goes up" countdown, and the 4 gifts are mentioned on the page.
